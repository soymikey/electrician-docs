# I 类（Type I）第 17–19 页

**Type I：** 在小型器具的维护、维修或修理中操作制冷剂的人，必须持 Type I，或持 Universal。机动车空调（MVAC）除外。

EPA 对小型器具的定义包括：工厂制造、出厂已充满、全封闭、制冷剂为 5 磅或更少的产品。分体系统不能由 Type I 技术人员维修。向维修或安装制冷和空调设备的人销售 CFC、HCFC、HFC 和 HFO，只限于按《清洁空气法》第 608 条取得 EPA 认证的技术人员。

类似 MVAC 的系统，无论制冷剂种类或数量，都不符合 Type I 设备认证的条件。把系统改成使用另一种制冷剂时，只能用 EPA SNAP 批准的替代品。不存在所谓的直接替换（drop-in）。EPA 不批准任何替代制冷剂作为直接替换来维修 R-22 或任何其他系统。

## 回收设备（Recovery Equipment）

维护、维修或修理含制冷剂的小型器具时，所用回收设备必须由 EPA 认可的设备检测机构认证。从小型器具回收制冷剂的设备，在压缩机不能运转时必须能回收 80% 的制冷剂，在压缩机能够运转时必须能回收 90%。用制冷剂秤，或用钢瓶内部浮子，都是可以接受的方法，用来监视回收罐的充装量不超过 80%。

任何为了维护、维修或修理而打开含 CFC、HCFC 或 HFC 设备的人，必须至少有一台自含式回收机可供使用。这条规则的例外，是只做小型器具的人。打开或维护、维修、修理含 CFC、HCFC 或 HFC 的 Type I 设备时，可以使用自含式（主动，active）回收设备，也可以使用被动式（passive）回收设备。被动式、依赖系统的（system-dependent）回收，可以把小型器具里的制冷剂收到一个不带压的容器里。用于含 HCFC 或 HFC 的设备时，依赖系统的或被动式回收设备，限用于最大充注量 15 磅。

回收 CFC、HCFC、HFC 和 HFO 的装置，断开时必须能手动关闭或自动关闭，以防止损失制冷剂。接表组检查系统压力时，软管两端应有手动阀或自封阀，以免制冷剂储存钢瓶充得过满。专为系统抽真空设计的普通真空泵，可以用来抽空一只回收钢瓶，使这只钢瓶充当回收装置。但它不能和带压的回收钢瓶或容器一起用来回收制冷剂。

## 回收方法（Recovery Techniques）

维修一台发现有泄漏的小型器具时，并不强制必须修泄漏，但建议尽可能修理或更换。开始回收之前，必须知道系统里是哪种制冷剂，以免在回收钢瓶里混放。把任何制冷剂混在同一台设备或同一只回收钢瓶里，都是不能接受的。从设备中回收 R-410A 或任何其他制冷剂时，应收到标明内容物的回收容器里，确保不会混合。R-744，也就是二氧化碳（CO₂），是超高压制冷剂，通常不需要回收。

如果怀疑回收钢瓶里的制冷剂被污染，应测量钢瓶的压力和温度，再和温压表比较。如果温压关系对不上，制冷剂很可能已被污染，应送到有资质的再生设施。

只有在制冷剂的压力和温度都稳定、并且是已知的时候，用温压表判断污染才有效。检查只装一种制冷剂的回收钢瓶里有没有不凝性气体（non-condensable）时，必须先让钢瓶温度稳定到室温，再用温压表读压力做比较。

小型器具上典型的检修口或工艺短管，是一段直管，用刺穿式检修阀（piercing access valve）刺入，以便加入或取出制冷剂，见图 16。在密封系统上安装任何检修接头之前，应先做泄漏试验，再开始回收，见图 17。无焊料的刺穿阀时间久了容易漏，修理完成后不应留在系统上。

从家用冰箱或任何其他器具回收制冷剂时，低压侧和高压侧都应安装检修阀，以提高回收速度。为了确保无霜冰箱或冷冻柜里的制冷剂全部取出，可以给化霜加热器通电，提高制冷剂温度，使液体汽化。一台压缩机正在运转、而且毛细管或节流装置完全堵塞的设备，只需要在高压侧装一只检修阀。如果装上并打开刺穿检修阀之后，设备压力是 0 psig，回收程序不能开始。

使用自含式（主动）回收装置，而被回收的制冷剂里有大量不凝性气体时，回收机高压侧和回收钢瓶里都可能出现过高压力。可以用温压表检查制冷剂里的不凝性气体。一只不含不凝性杂质、并且室温 80°F 存放的 R-134a 钢瓶，压力大约是 87 psig。只要钢瓶里还有液体制冷剂、并且没有杂质，压力和温度就应当和温压表一致。

回收和/或修理过程中，如果从制冷剂里闻到刺鼻气味，通常说明压缩机烧毁。从发生过压缩机烧毁的系统回收制冷剂时，要注意油被污染的迹象，因为有污染物时系统必须冲洗。用氮气加压或吹出杂物时，氮气可以排到周围空气中。

## 碳氢化合物（A3）制冷剂

许多 Type I 小型器具可以充注碳氢制冷剂。按 ASHRAE 标准 34，碳氢制冷剂分类为 A3，高度可燃。

碳氢制冷剂未被批准改造进现有的家用冰箱和冷冻柜。新制造的家用冰箱和冷冻柜，可以在工厂充注下列任何一种：R-290、R-441A、R-600a。这些制冷剂得到 EPA SNAP 批准，充注量限制在 150 g 或更少。

| 最大允许充注量，按 UL 60335-2-24:2017（SNAP 批准，EPA SNAP Ruling 22:2018） | |
| --- | --- |
| R-290、R-600a、R-441A | 150 g = 5.3 oz |

A3 制冷剂只能用在专门为它们设计的新设备上。这些系统必须全封闭，并且必须有规定的彩色标记，表明充的是可燃制冷剂。A3 制冷剂不被批准用于分体系统。

## 安全（Safety）

充有碳氢制冷剂的家用器具，必须在蒸发器上或附近、外露的制冷剂管、机器舱，以及冰箱外部，有永久性安全标记，见图 18。

回收制冷剂时，安全做法包括连接和拆开软管时戴安全眼镜和丁基衬里手套。用氮气做维修、检漏或吹扫时，氮气瓶必须带调节器。任何设备里都不得混合制冷剂。

制冷剂比空气重，会排开氧气，很大的制冷剂泄漏可能造成窒息。如果发生大量泄漏，例如满瓶钢瓶在封闭区域泄漏，又没有自给式呼吸器，应撤离并自然通风。高温下，CFC 和 HCFC 会分解成光气、盐酸和/或氢氟酸。
