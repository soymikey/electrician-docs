# B 组 · 锅炉房与辅助设备

Boiler room and auxiliary equipment

[返回参观总览](./index.md)

**现场分组 B · 11 张照片**

## 这一组怎么理解

从机房全景认识锅炉、烟道、给水机组、仪表、控制柜和辅助泵。学习时分清燃烧供热、给水补充、状态监测这几个任务。

现场同组的 Trane 控制柜和双泵用途仍待确认，不直接认定它们控制或服务某台锅炉。

以下设备名称是照片识别结果；分组及照片范围按你提供的现场文件夹保留。通用工作原理不代表已确认现场全部接线或管路。

## 4. IMG_9419 · 疑似烟道调节部件 / Possible draft regulator {#photo-9419}

[![疑似烟道调节部件 / Possible draft regulator · IMG_9419](/img/field-trip/government-building/IMG_9419.webp)](/img/field-trip/government-building/IMG_9419.webp)

**设备是什么（What it is）**

圆形活动部件疑似气压式烟道抽力调节器（Barometric Draft Regulator）。

**主要组件（Main components）**

| 主要组件（中英文） | 在哪里／照片依据 | 负责什么 |
|---|---|---|
| 圆管与开口 / Duct & opening | 照片可见，疑似烟道 | 为排烟及调节部件提供连接位置。 |
| 活动挡板 / Movable flap | 照片可见圆形活动部件 | 若确为气压式抽力调节器，可随压差变化开启。 |
| 转轴与平衡机构 / Pivot & balance | 候选调节器常见结构，细节未确认 | 让挡板对受力变化作出反应；不能由照片推定调节方法。 |

**结合照片看（What to look for）**

大型金属圆管上有圆形活动部件。 观察挡板与圆管的位置。下述是候选设备的原理，型号未确认前不视为本机定论。

**工作原理（How it works）**

如果确认是这种调节器，烟道负压变化会改变活动挡板的受力。抽力较强时，挡板开启让一部分机房空气进入烟道，帮助稳定抽力；其用途是排烟控制，不是调节供给房间的冷暖风。

原理参考：[Field Controls 烟道抽力控制](https://www.fieldcontrols.com/draft/)。

**待确认事项**

疑似烟道抽力调节器；需核对部件铭牌，不按照片推定操作方法。

## 5. IMG_9420 · 锅炉给水机组 / Boiler feedwater unit {#photo-9420}

[![锅炉给水机组 / Boiler feedwater unit · IMG_9420](/img/field-trip/government-building/IMG_9420.webp)](/img/field-trip/government-building/IMG_9420.webp)

**设备是什么（What it is）**

这是标有 Boiler Feedwater Unit 的锅炉给水机组，作用是向蒸汽锅炉补入给水。

**主要组件（Main components）**

| 主要组件（中英文） | 在哪里／照片依据 | 负责什么 |
|---|---|---|
| 给水箱 / Feedwater tank | 机组罐体部分可见 | 容纳待送入锅炉的给水。 |
| 给水泵 / Feed pump | 机组配套，面板可见泵编号 | 把水送入锅炉；各泵位置和管路需进一步核对。 |
| 开关与控制面板 / Switches & controls | 照片正面可见 | 提供泵和锅炉相关的控制接口。 |
| 水位检测 / Level sensing | 通用配套，传感器未在本图确认 | 锅炉水位用于给水需求判断，水箱水位用于箱内水量管理；两者不应混为同一测量点。 |

**结合照片看（What to look for）**

清楚标有 BOILER FEEDWATER UNIT、SHIPCO PUMPS，以及锅炉与泵的控制标识。 看泵的编号和 Boiler-1、Boiler-2 标识；面板说明服务对象，但完整管路仍需图纸。

**工作原理（How it works）**

蒸汽离开锅炉后，锅炉里的水量会减少。典型给水系统由水位控制信号启动或调节给水泵，把水箱内的水送进锅炉；给水泵须克服锅炉侧压力及管路阻力。给水箱液位控制与锅炉水位控制是两个不同任务。

原理参考：[Shipco 锅炉给水机组](https://www.shipcopumps.com/products/)。

**待确认事项**

身份有文字支持；给水箱、泵和各台锅炉的连接需图纸确认。

## 把设备连起来：整组怎样运行

先回顾上面的设备与组件，再阅读下面的通用流程。这里是原理复习，不是现场已确认的管路图，也不是启停操作步骤。

### 简化运行流程

**能量路径（蒸汽锅炉通用原理）：** 燃料与空气燃烧 → 热量经受热面传给水 → 水吸热产生蒸汽 → 蒸汽送往用热设备；烟气经排烟通道排出。

**水的路径（通用原理）：** 给水箱 → 给水泵 → 锅炉 → 蒸汽 → 用热处凝结；可回收的凝结水经相应回收设备返回给水侧，损失部分由补充水补足。现场回收路径尚未完整确认。

**控制路径（通用原理）：** 压力、水位等测量 → 控制器判断 → 调节燃烧或给水；HMI 显示状态。辅助泵、水处理与控制柜并不按照片顺序串成一根管道。
