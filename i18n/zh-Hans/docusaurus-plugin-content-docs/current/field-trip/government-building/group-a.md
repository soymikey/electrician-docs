# A 组 · 热水设备与补风机组

Hot-water equipment and makeup-air unit

## 这一组怎么理解

本组保留现场放在一起的立式热水设备、循环泵、恒温混水阀和 Trane 补风机组。先认识热水设备如何储热、循环和调温，再单独看补风机组如何处理空气。

罐形热水设备与补风机组是否直接连接，照片尚未证明；不能把空间上的同组直接画成水路连接。

以下设备名称是照片识别结果；分组及照片范围按你提供的现场文件夹保留。通用工作原理不代表已确认现场全部接线或管路。

## 1. IMG_9410 · 立式热水设备 / Vertical hot-water equipment {#photo-9410}

[![立式热水设备 / Vertical hot-water equipment · IMG_9410](/img/field-trip/government-building/IMG_9410.webp)](/img/field-trip/government-building/IMG_9410.webp)

**设备是什么（What it is）**

这是两台立式罐形热水设备；目前先按热水加热或储存设备学习。

**主要组件（Main components）**

| 主要组件（中英文） | 在哪里／照片依据 | 负责什么 |
|---|---|---|
| 外壳 / Jacket | 照片可见，罐体外侧 | 保护内部结构；外壳不等于承水内胆。 |
| 内胆 / Storage vessel | 通用结构，内部未拍到 | 容纳和储存热水；本机实际结构待型号确认。 |
| 热源与温控 / Heat source & thermostat | 通用配置，内部未拍到 | 给水加热并按温度需求控制；电热、燃气或外部换热形式尚未确认。 |
| 铜管与接线 / Pipes & wiring | 外部连接，照片可见 | 分别承担流体连接和电气连接，具体接口用途待确认。 |

**结合照片看（What to look for）**

两台立式圆筒设备，附近有铜管和电气接线。 把罐体、连接铜管和电气接线分开看；有电线不等于已确认采用电阻加热。

**工作原理（How it works）**

储水式热水设备先把热量存进罐内的水，再向用水处供应。水温下降时，温控器使热源重新加热；外层保温减少热损失。热源可以是电热元件、燃气或外部换热，现场属于哪一种仍须铭牌确认。

原理参考：[DOE 储水式热水设备](https://www.energy.gov/cmei/buildings/consumer-water-heaters)。

**待确认事项**

与 9415、9435 对照；是否均为同型号待确认。

## 2. IMG_9413 · 小型循环泵 / Circulator pumps {#photo-9413}

[![小型循环泵 / Circulator pumps · IMG_9413](/img/field-trip/government-building/IMG_9413.webp)](/img/field-trip/government-building/IMG_9413.webp)

**设备是什么（What it is）**

这是小型循环泵，用来推动水在管路里循环。

**主要组件（Main components）**

| 主要组件（中英文） | 在哪里／照片依据 | 负责什么 |
|---|---|---|
| 电动机 / Motor | 照片可见的电机外壳 | 将电能转为旋转机械能。 |
| 泵体 / Pump casing | 照片可见，连接管道处 | 容纳流道和内部转动部件。 |
| 叶轮 / Impeller | 常见离心泵内部结构，未拍到 | 随电机旋转，把能量传给水。 |
| 连接管路 / Connected piping | 外部配套，照片可见 | 提供水流通道；不是泵的内部组件。 |

组件参考：[KSB 泵壳与内部转子](https://www.ksb.com/en-global/centrifugal-pump-lexicon/article/pump-casing-1118596)。

**结合照片看（What to look for）**

红色及金色泵体、保温管道与电气连接。 辨认电机、泵体和连接管路。循环泵负责输送，热源负责主要加热。

**工作原理（How it works）**

以常见离心式循环泵为例：电动机带动叶轮，把机械能传给水，建立压差，克服管道阻力。用于热水回水时，循环能让热水持续回到热源附近，减少末端等待；这张照片的具体用途仍待确认。

原理参考：[KSB 离心泵设计基础](https://configurator.ksbindia.co.in/GeneralUtilities/KSBDocumentation/MISC/Centrifugal_design.pdf)。

**待确认事项**

暂归热水循环；具体回路及主备关系待确认。

## 3. IMG_9414 · 恒温混水阀组 / Thermostatic mixing valve assembly {#photo-9414}

[![恒温混水阀组 / Thermostatic mixing valve assembly · IMG_9414](/img/field-trip/government-building/IMG_9414.webp)](/img/field-trip/government-building/IMG_9414.webp)

**设备是什么（What it is）**

这是恒温混水阀组（Thermostatic Mixing Valve），用于调节冷热水混合后的出水温度。

**主要组件（Main components）**

| 主要组件（中英文） | 在哪里／照片依据 | 负责什么 |
|---|---|---|
| 阀体与接口 / Valve body & ports | 照片中央阀组可见 | 连接各水路，容纳内部调节机构；各接口实际接法待确认。 |
| 温度调节部件 / Temperature adjustment | 照片阀体前方可见 | 用于设定目标混水温度；实际刻度值未核实。 |
| 感温元件与调节机构 / Thermal element & mechanism | 恒温阀通用内部结构，未拍到 | 感受混水温度，并改变冷热水的相对通道开度；本机具体结构需型号资料。 |
| 温度表与隔断阀 / Thermometer & isolation valves | 外部配套，照片可见 | 温度表指示温度，隔断阀控制管段通断；不是感温元件本身。 |

组件参考：[Leonard 混水阀结构参考（非现场型号确认）](https://www.leonardvalve.com/api/file/13373/pdf/G-AT%20%5BCompatibility%20Mode%5D.pdf)。

**结合照片看（What to look for）**

可读 LEONARD THERMOSTATIC；可见大小阀组、温度表及 HOT WATER RETURN 标签。 找中央阀体、冷热标记、连接铜管和温度表。大小两组阀的分工尚不能单靠照片确定。

**工作原理（How it works）**

混合水温度变化会使内部感温元件动作，改变冷热水通道的相对开度。出水偏热时减少热水比例、增加冷水比例；偏冷时反向调节。它通过混合调温，本身不制造热量。

原理参考：[Caleffi 恒温混水阀原理](https://www.caleffi.com/sites/default/files/media/external-file/48290_EN.pdf)。

**待确认事项**

可用于学习热水温度控制；实际设定温度和供回水接法待确认。

## 把设备连起来：整组怎样运行

先回顾上面的设备与组件，再阅读下面的通用流程。这里是原理复习，不是现场已确认的管路图，也不是启停操作步骤。

### 简化运行流程

**热水支线（通用原理）：** 热源给水加热 → 储存热水 → 在用水处按需要混合调温 → 供给用水点。若有回水循环，回水泵推动回水返回加热或储存侧；它不是所有出水必经的串联步骤。

**空气支线（通用原理）：** 风机推动补充空气 → 经过配置的过滤与换热部件 → 由风管送出。实际部件顺序依机组设计而定。

这组包含两条学习支线。先看热水设备，再看补风机组；照片尚未证明两者直接连接。
