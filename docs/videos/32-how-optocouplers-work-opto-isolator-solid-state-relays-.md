## 学习目标
理解 optocoupler 如何用光隔离控制信号，并认识 solid state relay 的基本思想。

## 核心知识点
- 继电器用线圈控制触点动作。
- NO、NC、COM 是读继电器图的关键。
- 控制电路和负载电路可以隔离。
- 线圈断电可能产生反向电压。
- HVAC、控制柜、泵和风机系统常见继电器。

## 美国电工学习重点
- 这部分对 HVAC、泵、风机、控制柜、门铃变压器和设备排故很有帮助。
- 先会读铭牌、端子、线圈、触点和控制图，再深入计算。
