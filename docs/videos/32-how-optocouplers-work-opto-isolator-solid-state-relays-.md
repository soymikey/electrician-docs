## 核心知识点
- 继电器用线圈控制触点动作。
- NO、NC、COM 是读继电器图的关键。
- 控制电路和负载电路可以隔离。
- 线圈断电可能产生反向电压。
- HVAC、控制柜、泵和风机系统常见继电器。

## 美国电工学习重点
