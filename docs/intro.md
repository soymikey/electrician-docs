# Electrician Docs

This documentation turns The Engineering Mindset's **Electrical Engineering Basics** playlist into a practical learning path for beginners studying US residential electricity, electrical safety, tools, motors, transformers, three-phase power, and low-voltage electronics.

:::danger Safety boundary
This site is for concept learning. It does not replace the NEC, local code, licensing programs, jobsite supervision, PPE requirements, equipment nameplates, or qualified professional judgment.
:::

## Start here

- New to the topic: read [Quick Start](getting-started/quick-start.md).
- Need the mental model: read [Core Concepts](core-concepts/mental-model.md).
- Studying US homes: read [US Residential Circuits](us-residential/split-phase.md).
- Thinking about safety: read [Electrical Safety](safety/electrical-safety.md).
- Checking formulas and field reminders: use the [Cheatsheet](formula-reference.md).
- Looking for a lesson: open the [Video Index](video-index.md).
- Looking up terms: use the [Glossary](glossary.md).

## Learning principle

Learn electricity like you would learn a serious technical system: build the model first, keep a glossary nearby, test yourself often, and respect the fact that mistakes have physical consequences.
