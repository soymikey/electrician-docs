# Electrical and HVACR Course Notes

Study alongside Electrical and HVACR classes using four textbook collections. YouTube lessons supplement classroom learning, with separate sections for field trips, jobsite English, and reference material.

## Textbook collections

| Textbook | Available material | Entry |
| --- | --- | --- |
| NCCER Core, 6th Edition | Ten construction foundation modules; language availability varies by module | [Core catalog](/docs/nccer-core) |
| Electrical Level 1, 12th Edition | Eleven modules and a module review, in Chinese | [Electrical](/docs/electrical/level-1/26101-occupational-overview-the-electrical-industry) |
| HVACR Level 1, 6th Edition | Nine modules and a module review, in Chinese | [HVACR](/docs/hvacr/level-1/03101-introduction-to-hvacr) |
| EPA 608 Preparatory Manual | Introduction, Core, Type I, Type II, and Type III | [EPA 608](/docs/hvacr/epa-608/introduction) |

## Find your material

Start with [Quick Start](/docs/getting-started/quick-start). Browse [field trips](/docs/field-trip), [jobsite English](/docs/spoken-english/main-panel-phrases), or the [YouTube video index](/docs/video-index).

[YouTube stage quizzes](/docs/quizzes/core-concepts) test the six supplementary video topics, not the four textbooks. The [formula reference](/docs/formula-reference) and [glossary](/docs/glossary) currently focus on electrical basics.
