# 美国电工学习文档

这套文档把 The Engineering Mindset 的《电工基础》（`Electrical Engineering Basics`）43 集播放列表整理成前端工程师更熟悉的文档结构。它不是按视频顺序堆笔记，而是按学习路线组织：先建立思维模型（mental model），再进入美国住宅电路、安全工具、控制系统和进阶主题。

:::danger 安全边界
这套资料用于学习概念，不能替代 NEC、当地规范（local code）、执照课程、现场师傅监督或 PPE。涉及带电测试、配电箱、240V/三相系统、故障排查时，先断电、验电，并确认你有资格做这件事。
:::

## 你应该从哪里开始

- 新手先读：[入门指南](getting-started/quick-start.md)
- 想建立概念：读 [核心概念](core-concepts/mental-model.md)
- 想学美国住宅：读 [美国住宅电路](us-residential/split-phase.md)
- 想避免危险：读 [安全](safety/electrical-safety.md)
- 想自测掌握度：做 [阶段测验](quizzes/core-concepts.mdx)
- 想查视频：读 [视频索引](video-index.md)
- 想查计算：读 [公式速查](formula-reference.md)
- 想查英文词：读 [术语表](glossary.md)

## 学习原则

像学一个 npm 包一样学电工：先读入门指南，理解核心概念，再查术语表和视频笔记。区别是，电工的错误有物理后果，所以安全不是附录，而是核心模块。
