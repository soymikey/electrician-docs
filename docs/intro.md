# 美国电工学习文档

这套文档把 The Engineering Mindset 的 `Electrical Engineering Basics` 43 集播放列表整理成前端工程师更熟悉的 docs-as-code 结构。它不是按视频顺序堆笔记，而是按学习路线组织：先建立 mental model，再进入美国住宅电路、安全工具、控制系统和进阶主题。

:::danger 安全边界
这套资料用于学习概念，不能替代 NEC、当地 code、执照课程、现场师傅监督或 PPE。涉及带电测试、配电箱、240V/三相系统、故障排查时，先断电、验电，并确认你有资格做这件事。
:::

## 你应该从哪里开始

- 新手先读：[Getting Started](getting-started/quick-start.md)
- 想建立概念：读 [Core Concepts](core-concepts/mental-model.md)
- 想学美国住宅：读 [US Residential](us-residential/split-phase.md)
- 想避免危险：读 [Safety](safety/electrical-safety.md)
- 想查视频：读 [Video Index](video-index.md)
- 想查英文词：读 [Glossary](glossary.md)

## 学习原则

像学一个 npm 包一样学电工：先读 Quick Start，理解核心概念，再查 API Reference。区别是，电工的错误有物理后果，所以 Safety 不是附录，而是核心模块。
