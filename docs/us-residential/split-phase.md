# US Residential System

美国住宅电工的核心是理解 `120/240V split-phase`、`hot`、`neutral`、`ground`、`service panel` 和各类分支电路。

## 关键模型

- 任一 hot leg 到 neutral 通常约 120V。
- 两个 hot leg 之间通常约 240V。
- neutral 是正常回流导体。
- equipment grounding conductor 是故障保护路径。
- 120V 常用于普通插座和照明，240V 常用于大功率负载。

:::warning 不要随意混接 neutral 和 ground
neutral 和 ground 的连接位置受 code 限制。不要因为它们在某些测量中看起来相近，就在任意盒子里混接。
:::
