# 美国住宅电路系统（US Residential System）

美国住宅电工的核心是理解 120/240V 分相供电（split-phase）、火线（hot）、零线（neutral）、地线（ground）、总配电箱（service panel）和各类分支电路。

## 关键模型

- 任一火线相线（hot leg）到零线（neutral）通常约 120V。
- 两个火线相线（hot legs）之间通常约 240V。
- 零线（neutral）是正常回流导体。
- 设备接地导体（equipment grounding conductor）是故障保护路径。
- 120V 常用于普通插座和照明，240V 常用于大功率负载。

:::warning 不要随意混接零线和地线
零线（neutral）和地线（ground）的连接位置受电气规范（code）限制。不要因为它们在某些测量中看起来相近，就在任意盒子里混接。
:::
