# Common Wiring Patterns

## Receptacles

插座学习重点不是背颜色，而是理解端子功能：hot、neutral、ground，以及 break-off tab 如何影响上下插孔的连接。

## Three-Way / Four-Way Switching

三路开关用于两个位置控制同一负载，四路开关插在两个三路开关之间，用于三个或更多位置控制。关键术语是 `common`、`traveler`、`line`、`load`、`switched leg`。

:::warning 颜色不是唯一事实来源
旧房或被改过的线路可能不符合你期待的颜色规则。要用端子、路径、测试和图纸判断。
:::
