# Quick Start

## 推荐学习顺序

1. Core Concepts：电压、电流、电阻、功率、串联、并联。
2. US Residential：120/240V split-phase、hot、neutral、ground、插座和开关。
3. Safety：breaker、GFCI、hot-to-ground、触电风险和验电。
4. Tools：万用表和钳形表。
5. Motors & Transformers：变压器、电机、发电机和交流系统。
6. Three Phase & Industrial：三相、VFD、star-delta、power factor。
7. Low Voltage & Electronics：二极管、整流、电容、LED、晶体管、光耦、电位器。

## 每课怎么学

- 第一遍看视频，不暂停，先获得整体感觉。
- 第二遍读本 docs 的知识点和术语表。
- 第三遍遇到不懂再回到原视频，用时间戳字幕定位。
- 每课结束写三句话：它是什么、现场对应什么、危险在哪里。

## 前端工程师类比

- voltage：驱动力或势能差。
- current：真实流量。
- resistance：限制流量的阻抗。
- circuit：必须闭合的数据流路径。
- breaker/GFCI：保护边界，但保护对象不同。
