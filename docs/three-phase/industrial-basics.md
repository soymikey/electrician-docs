# 三相与工业电基础（Three Phase & Industrial Basics）

三相内容适合商业、工业、HVAC、泵、风机和电机控制方向。住宅新手不需要最先掌握计算，但应该知道三相为什么存在，以及它比普通 120V 住宅支路更危险。

## 关键主题

- 三相电（three phase）：三个相位相隔约 120 度。
- 功率因数（power factor）：真实做功和系统总负担之间的关系。
- 变频器（VFD）：通过变频控制电机速度。
- 星三角启动器（star-delta starter）：降低三相电机启动电流的方式。
