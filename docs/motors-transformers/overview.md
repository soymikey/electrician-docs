# Motors & Transformers

电机、发电机和变压器都离不开磁场。对初学电工来说，目标不是推导全部电磁学，而是能读懂设备铭牌、线圈、绕组、一次侧/二次侧、启动电流和保护要求。

## 学习重点

- transformer：通过交流磁场在绕组间传递能量。
- motor：把电能转换成机械能。
- generator/alternator：把机械能转换成电能。
- inductor/coil：线圈和磁场是控制电路与电机系统的基础。
