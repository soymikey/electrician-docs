# Tools & Measurement

## Multimeter

万用表可以测电压、电阻、导通和电流，但每一种测量方式的接法不同。测电压通常是并联跨接两个点；测电流通常需要串联或使用钳形表。

## Clamp Meter

钳形表测电流时通常要夹单根导体。如果同时夹 hot 和 neutral，两个方向相反的磁场通常会抵消，读数接近 0。

## 新手检查

- 仪表 CAT 等级是否适合现场？
- 表笔插孔是否正确？
- 档位是否正确？
- 电路是否已经断电并验电？
- 是否需要持证人员监督？
